# Instrucciones de Inicio para Acode IDE

## Copia y pega esto al iniciar una sesión con Acode:

```
Lee HANDOFF.md y .agents/AGENTS.md del proyecto antes de hacer 
cualquier cambio. Contienen el estado actual, tareas completadas, 
pendientes y reglas de diseño. Actualiza HANDOFF.md en CADA commit.
Si se acaba tu cuota, el otro asistente podrá continuar gracias 
a esos archivos.
```

## Si Acode se cortó sin actualizar HANDOFF.md:

Dile a Antigravity:
```
zcode hizo cambios, revisa git log y actualiza HANDOFF.md
```
